# Changelog

Todas as mudanças notáveis deste projeto serão documentadas neste arquivo seguindo [Keep a Changelog](https://keepachangelog.com/en/1.0.0/) e [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0-alpha.1] - 2026-04-03

### Adicionado
- **Arquitetura Hexagonal:** Estrutura inicial do projeto migrada para C++20.
- **Framework Qt6:** Configuração base para GUI (Wayland), Multimedia, DBus e Network.
- **TDD/ATDD:** Integração inicial com GoogleTest e CTest.
- **UI Base:** Placeholder para Dashboard com temas Breeze Dark/Light manuais.
- **Segurança:** Planejamento para suporte AES-256-GCM Zero-Cloud.
- **Exportação:** Suporte planejado para JSON, XML, CSV e Markdown.

### Legado
- Versão 0.3.6 movida para o diretório `./legacy` para servir de guia.
